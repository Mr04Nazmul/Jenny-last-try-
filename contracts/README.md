# NAZU Token

## Token specification

- Name: **NAZU**
- Symbol: **NAZU**
- Standard: **ERC-20**
- Target network: **Ethereum**
- Total supply: **21,000,000 NAZU**
- Decimals: **18**
- Minting: **fixed supply; no public mint function**

The contract mints the entire fixed supply once to the deployer address.

## Important

This repository contains the contract source only. It is **not deployed to Ethereum yet**.

Before mainnet deployment:
1. Review and test the contract.
2. Deploy to an Ethereum test network.
3. Verify the deployed source code.
4. Confirm the token allocation/treasury addresses.
5. Only then deploy to Ethereum mainnet.

Never put a wallet seed phrase or private key in this repository.
